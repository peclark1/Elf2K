This is a substantive content mismatch, not merely different Intel HEX record ordering. The correct monitor, HELP, SEDIT, BASIC and XMODEM spans strongly constrain investigation to four stock source/tool combinations, but do **not** establish the exact cause of their discrepancies. Treat these as **hypotheses**, not approved modifications.

## 3. Diagnosed assembler/build failures and scope of corrections

1. `forth.asm` RcAsm `INCLUDE config.inc ; comment` error: `sw/build/normalize-rcasm.py` used a doubly escaped regex, so the comment was read as filename content. Corrected regex and added parsing/idempotence regressions.
2. Visual/02 segfault: the pinned Asm/02 `#include` parser treats quoted filenames as literal path content; converted relocated include paths to unquoted `#include`, in the disposable working source only.
3. Visual/02 bare `include` directives and an actual orphan upstream `#endif`: deterministic preparation converts only recognized syntax and removes only the uniquely identified dangling preprocessor directive; other imbalances cause a hard failure.
4. Visual/02 unresolved `CODE`, `DATA`, BIOS services and `EDTASM` names: pinned public Asm/02 substitutes macros only once and case-sensitively. The build now generates stock `config.inc`, converts the historical BIOS EQU declarations to preprocessor definitions after TASM boots, resolves nested BIOS addresses from those generated stock constants, and inserts the four STGROM console aliases equivalent to other Visual/02 target profiles in a disposable source copy.
5. All nine original stock segments now assemble; ROM merge and checksum tools finish successfully. No components were dropped, no RAM/ROM mapping changes, and no new AVI configuration was added.

## 4. Reproduction procedure, pinned versions and CI

Run from a clean checkout of this branch on Ubuntu 24.04:

```bash
sudo apt-get update && sudo apt-get install -y build-essential git python3
python3 -m unittest discover -s sw/build/tests -v
bash -n sw/build/build-stock.sh sw/build/prepare-deps.sh sw/build/reproduce-stock.sh
bash sw/build/reproduce-stock.sh
```

`reproduce-stock.sh` removes/recreates two independent build directories (`first`, `second`), uses the same explicitly pinned external source revisions (no floating upstream heads), and compares both binary images to each other and then to the original. It deliberately exits **1** because of the reference discrepancy. Individual clean assemblies and 32 KiB binary output are successful. Reference SHA and blob are checked *before* builds.
